# 📖 ديوان — دفترك الذكي

منصة SaaS لإدارة الأعمال الصغيرة بالعربي.

## 🚀 التشغيل

### Terminal 1 — Backend

    cd backend
    npm install
    npm run dev
    # http://localhost:3000

### Terminal 2 — Frontend

    cd frontend
    npm install
    npm run dev
    # http://localhost:5173

## 📱 الصفحات

| المسار | الوصف |
|---|---|
| / | الصفحة الرئيسية |
| /login | تسجيل الدخول |
| /dashboard | لوحة التحكم |
| /expenses | المصاريف |
| /about | عن ديوان |

## 💸 ميزة المصاريف

- تسجيل مصروف في ثوانٍ
- 8 فئات (إيجار، كهرباء، رواتب، بضاعة...)
- تقارير حسب الفئة
- فلترة (اليوم/الأسبوع/الشهر/الكل)
- حفظ محلي (localStorage)
- مزامنة مع Backend
- صافي الربح = مبيعات - مصاريف

## 🎯 الميزات القادمة

- ربط المصاريف بالمبيعات
- ميزانية شهرية لكل فئة
- تنبيهات ذكية (AI)
- كشف المصاريف المتكررة
- تصدير PDF
- مشاركة واتساب
